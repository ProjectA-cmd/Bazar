# Базар — сайт объявлений

Простой сайт-доска объявлений: категории «Техника», «Вещи», «Игрушки», карточки товаров с описанием и характеристиками, корзина, добавление и удаление товаров, комментарии и заказ через WhatsApp (номер `87775477610`).

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `bazar-site`).
2. Загрузите в него файл `index.html` из этого архива (через веб-интерфейс «Add file → Upload files», либо через git).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<ваш-логин>.github.io/bazar-site/`

Никакой сборки, сервера или npm не требуется — это один статический HTML-файл.

## Важно: как хранятся данные

Это статический сайт (GitHub Pages не запускает сервер и базу данных). Поэтому:

- Товары, комментарии и заказы сохраняются в **localStorage браузера** — то есть **у каждого посетителя свой набор данных**, они не видны другим людям и не синхронизируются между устройствами.
- Это удобно для демонстрации и личного использования (например, только вы добавляете и удаляете товары со своего телефона/компьютера), но **не подходит**, если нужен один общий каталог для всех покупателей.

### Если нужен общий каталог для всех пользователей

Понадобится настоящий бэкенд с базой данных, например:
- Firebase / Supabase (бесплатный план подходит для старта) — база данных + хранение файлов.
- Или собственный сервер (Node.js/Express + PostgreSQL/MongoDB), задеплоенный на Render, Railway и т.п.

Тогда вместо `localStorage` сайт будет читать/писать товары, заказы и комментарии в эту базу — и все посетители будут видеть одни и те же данные.

## Про уведомления в WhatsApp

Браузер не может сам, без участия человека, отправлять сообщения в WhatsApp — это требует официального WhatsApp Business API (например, через Twilio или 360dialog) с отдельным сервером и оплатой.

Поэтому на сайте реализован рабочий вариант «в один клик»:
- При оформлении заказа открывается WhatsApp с уже готовым текстом заказа (имя, телефон, список товаров) — остаётся нажать «Отправить».
- Кнопка «Спросить» под товаром открывает WhatsApp с вопросом по конкретному товару.
- Кнопка «📊 Отчёт» показывает сумму продаж за сегодня и одним кликом открывает готовое сообщение-отчёт в WhatsApp.

Полностью автоматическая отправка (без клика, по расписанию, из фонового задания) требует отдельного сервера с интеграцией WhatsApp Business API.

На сайте есть кнопка **«🔒 Вход»** в шапке. После входа появляются кнопки «Добавить товар», «🗑 Удалить» у каждого товара и «📊 Отчёт».

Логин и пароль по умолчанию:

- Пароль: `bazar2026`

**Обязательно смените их** перед публикацией сайта: откройте `index.html`, найдите строки

```js
const ADMIN_LOGIN = "admin";
const ADMIN_PASSWORD = "bazar2026";
```

и впишите свои значения.

⚠️ Это защита на уровне интерфейса, а не настоящая система безопасности: логин и пароль хранятся в коде страницы и видны любому, кто откроет исходный код страницы (правая кнопка мыши → «Просмотреть код» / F12). Такой защиты достаточно, чтобы случайные посетители не могли редактировать каталог, но не достаточно против человека, который специально хочет обойти пароль. Для настоящей защиты нужен сервер, который сам проверяет пароль и не отдаёт его в браузер (см. раздел про общий каталог выше).
